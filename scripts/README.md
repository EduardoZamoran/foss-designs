# scripts/

Intentionally **unused**. These files are kept as a possible future automation
and are not part of the current workflow, which is fully manual
(`iverilog`, `vvp`, `gtkwave`).

| File | Idea |
|---|---|
| `sim.mk` | Common makefile to build and run a project's simulation |
| `new_project.sh` | Creates the folder skeleton of a new project |

Neither file is executed by anything in this repository.
